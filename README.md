# 앳더모먼 CONTACT 입력폼

[www.miacle.co.kr/atmoment](https://www.miacle.co.kr/atmoment) 하단 CONTACT 영역을
아임웹 입력폼(`b202609115a34b122e2d20`)으로 접수되는 문의 폼으로 만드는 코드입니다.

접수 처리는 아임웹 입력폼 위젯이 그대로 담당하고, 이 코드는 그 위젯을 디자인된 CONTACT
카드 안으로 옮겨 꾸미는 역할만 합니다. 그래서 **별도 서버나 DB 없이** 기존처럼
관리자 > 입력폼에서 문의를 확인할 수 있고, 스팸 차단·알림 메일도 아임웹 기본 기능을 씁니다.

## 빠른 시작

1. 관리자 > 콘텐츠 > 입력폼에서 항목 10개를 만듭니다 → [설정 가이드](docs/SETUP.md#1단계--입력폼-항목-만들기)
2. `/atmoment` 편집기에서 CONTACT 자리에 **[코드] 위젯**을 놓고,
   그 아래에 **[입력폼] 위젯**을 놓습니다.
3. [`dist/imweb-code-widget.html`](dist/imweb-code-widget.html) 전체를 복사해 코드 위젯에 붙여넣습니다.
4. 실제 페이지에서 테스트 문의를 한 건 보내 접수를 확인합니다.

자세한 절차와 문제 해결은 **[docs/SETUP.md](docs/SETUP.md)** 를 봐주세요.

## 디자인 미리보기

`preview/index.html` 을 브라우저로 열면 실제 화면을 확인할 수 있습니다.
아임웹 입력폼 위젯을 흉내 낸 모의 폼이 함께 들어 있어, 폼이 카드 안으로 이동하는
동작까지 그대로 재현됩니다. (제출해도 실제로 전송되지 않는 데모입니다.)

## 파일 구성

| 경로 | 설명 |
|---|---|
| `dist/imweb-code-widget.html` | **아임웹에 붙여넣는 결과물** (자동 생성 — 직접 수정하지 마세요) |
| `src/contact-section.html` | CONTACT 섹션 마크업 — 제목·소개문·연락처 |
| `src/contact-form.css` | 스타일. 맨 위 토큰만 고치면 색상·여백이 한 번에 바뀝니다 |
| `src/contact-form.js` | 폼 이동, 연락처 자동 하이픈, 글자 수 카운터, 중복 제출 방지 |
| `preview/index.html` | 디자인 미리보기 (자동 생성) |
| `build.js` | `src/` → `dist/`, `preview/` 생성 |
| `docs/SETUP.md` | 아임웹 관리자 설정 가이드 |

## 수정 방법

`src/` 안의 파일을 고친 뒤 다시 빌드합니다.

```bash
node build.js
```

`dist/imweb-code-widget.html` 과 `preview/index.html` 이 다시 만들어집니다.
빌드 결과물을 직접 고치면 다음 빌드 때 덮어써지니 주의해 주세요.

## 설계 메모

- **아임웹 위젯의 내부 클래스명에 의존하지 않습니다.** 아임웹 업데이트로 마크업이 바뀌어도
  깨지지 않도록, `.atm-contact` 범위 안의 요소 *종류*(`input` / `select` / `textarea` / `button`)를
  기준으로 스타일을 적용합니다. 입력폼 항목을 추가·삭제·재정렬해도 디자인이 유지됩니다.
- **폼 제출을 가로채지 않습니다.** 스크립트는 `preventDefault` 를 호출하지 않으므로,
  스크립트가 실패하더라도 접수는 아임웹 기본 동작으로 정상 처리됩니다.
- **점진적 향상.** 입력폼 위젯을 찾지 못하면 폼은 원래 자리에 그대로 남아 동작합니다.
  디자인만 기본형으로 보일 뿐 접수가 누락되지 않습니다.

## 확인된 동작

Chromium 기준 데스크톱(1440px)·모바일(390px)에서 21개 항목을 검증했습니다.
폼 이동, 2단/1단 반응형 전환, 연락처 자동 하이픈(휴대폰·서울 지역번호), 글자 수 카운터,
iOS 확대 방지(16px), 가로 스크롤 없음, 콘솔 에러 없음.
