# 미아클 CONTACT 입력폼

미아클 사이트의 CONTACT 영역을 아임웹 입력폼(`b202609115a34b122e2d20`)으로
접수되는 문의 폼으로 만드는 코드입니다.

| 페이지 | 붙여넣을 파일 | 상태 |
|---|---|---|
| [홈페이지 메인](https://www.miacle.co.kr/) | `dist/main/imweb-code-widget.html` | 승인 대기 |
| [앳더모먼](https://www.miacle.co.kr/atmoment) | `dist/atmoment/imweb-code-widget.html` | 메인 승인 후 적용 |

페이지마다 다른 건 **문구뿐**입니다. 디자인·동작·접수 경로는 완전히 같습니다.

접수 처리는 아임웹 입력폼 위젯이 그대로 담당하고, 이 코드는 그 위젯을 디자인된 CONTACT
카드 안으로 옮겨 꾸미는 역할만 합니다. 그래서 **별도 서버나 DB 없이** 기존처럼
관리자 > 입력폼에서 문의를 확인할 수 있고, 스팸 차단·알림 메일도 아임웹 기본 기능을 씁니다.

## 빠른 시작

1. 관리자 > 콘텐츠 > 입력폼에서 항목 10개를 만듭니다 → [설정 가이드](docs/SETUP.md#1단계--입력폼-항목-만들기)
2. 해당 페이지 편집기에서 CONTACT 자리에 **[코드] 위젯**을 놓고,
   그 아래에 **[입력폼] 위젯**을 놓습니다.
3. `dist/<페이지>/imweb-code-widget.html` 전체를 복사해 코드 위젯에 붙여넣습니다.
4. 실제 페이지에서 테스트 문의를 한 건 보내 접수를 확인합니다.

자세한 절차와 문제 해결은 **[docs/SETUP.md](docs/SETUP.md)** 를 봐주세요.

## 톤 바꾸기

섹션 태그의 `data-atm-theme` 한 값으로 전체 톤이 바뀝니다.

| 값 | 결과 |
|---|---|
| `dark` | 어두운 톤 + 브랜드 레드 — 기존 아임웹 폼과 같은 계열 (**현재 기본값**) |
| `light` | 밝은 톤 (웜 오프화이트 + 먹색) |
| `auto` | 보는 사람의 기기 설정을 따라감 |

색을 더 세밀하게 맞추려면 `src/contact-form.css` 맨 위 테마 블록의 토큰만 고치면 됩니다.
브랜드 레드는 `--atm-accent` 한 줄입니다.

## 디자인 미리보기

`preview/main.html` · `preview/atmoment.html` 을 브라우저로 열면 실제 화면을
확인할 수 있고, 상단 버튼으로 다크/라이트를 바로 비교할 수 있습니다.
아임웹 입력폼 위젯을 흉내 낸 모의 폼이 함께 들어 있어, 폼이 카드 안으로 이동하는
동작까지 그대로 재현됩니다. (제출해도 실제로 전송되지 않는 데모입니다.)

## 파일 구성

| 경로 | 설명 |
|---|---|
| `dist/<페이지>/imweb-code-widget.html` | **아임웹에 붙여넣는 결과물** (자동 생성 — 직접 수정하지 마세요) |
| `src/copy.json` | 페이지별 문구 — 제목·소개문·톤. 페이지를 늘리려면 여기에 추가 |
| `src/contact-section.html` | CONTACT 섹션 템플릿 — 문구는 copy.json 에서 채워집니다 |
| `src/contact-form.css` | 스타일 + 테마(다크/라이트). 맨 위 토큰만 고치면 전체가 바뀝니다 |
| `src/contact-form.js` | 폼 이동, 필수/선택 배지, 선택지 알약 버튼, 연락처 자동 하이픈, 글자 수 카운터, 중복 제출 방지 |
| `preview/<페이지>.html` | 디자인 미리보기, 테마 전환 버튼 포함 (자동 생성) |
| `build.js` | `src/` → `dist/`, `preview/` 생성 |
| `docs/SETUP.md` | 아임웹 관리자 설정 가이드 |

## 수정 방법

`src/` 안의 파일을 고친 뒤 다시 빌드합니다.

```bash
node build.js
```

`dist/imweb-code-widget.html` 과 `preview/index.html` 이 다시 만들어집니다.
빌드 결과물을 직접 고치면 다음 빌드 때 덮어써지니 주의해 주세요.

## 설계 메모

- **아임웹 위젯의 내부 클래스명에 의존하지 않습니다.** 아임웹 업데이트로 마크업이 바뀌어도
  깨지지 않도록, `.atm-contact` 범위 안의 요소 *종류*(`input` / `select` / `textarea` / `button`)를
  기준으로 스타일을 적용합니다. 입력폼 항목을 추가·삭제·재정렬해도 디자인이 유지됩니다.
- **폼 제출을 가로채지 않습니다.** 스크립트는 `preventDefault` 를 호출하지 않으므로,
  스크립트가 실패하더라도 접수는 아임웹 기본 동작으로 정상 처리됩니다.
- **점진적 향상.** 입력폼 위젯을 찾지 못하면 폼은 원래 자리에 그대로 남아 동작합니다.
  디자인만 기본형으로 보일 뿐 접수가 누락되지 않습니다.

## 확인된 동작

Chromium 기준 데스크톱(1440px)·모바일(390px)에서 54개 항목을 검증했습니다.
폼 이동, 필수/선택 표시, 서비스 알약 버튼과 선택 강조, 다크/라이트 전환,
**WCAG AA 명암비(본문·제목·버튼 글자 모두 4.5:1 이상)**, 2단/1단 반응형 전환,
연락처 자동 하이픈, 글자 수 카운터, iOS 확대 방지(16px), 가로 스크롤 없음,
두 페이지 빌드 결과물에 미치환 문구 없음, 콘솔 에러 없음.

## 필수 / 선택 구분

관리자에서 필수 여부만 켜고 끄면 화면 표시가 자동으로 따라갑니다.
필수는 빨간 `*`, 선택은 회색 `선택` 배지 — 색이 아니라 **형태로도 구분**되므로
색 구분이 어려운 분들도 알아볼 수 있습니다. 폼 맨 위에는 범례가 항상 표시됩니다.
