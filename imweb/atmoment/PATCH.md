# 앳더모먼 CONTACT — 아임웹 입력폼 연동 패치

`miacle.imweb.me/admin/design` → 앳더모먼 → **코드 에디터**에서 적용합니다.

---

## 먼저 확인하신 내용

현재 코드를 확인한 결과 세 가지가 나왔습니다.

### 1. 문의가 아임웹으로 들어오지 않고 있습니다 ⚠️

```
action="https://formsubmit.co/miaclife@naver.com"
FORMSUBMIT_ENDPOINT = 'https://formsubmit.co/ajax/miaclife@naver.com'
```

**formsubmit.co** 라는 외부 무료 서비스를 거쳐 네이버 메일로만 발송됩니다.
그래서 아임웹 관리자 > 입력폼에는 **접수 기록이 하나도 남지 않습니다.**
메일이 누락되거나 그 서비스가 멈추면 문의를 되찾을 방법이 없습니다.

### 2. 첨부한 이미지가 실제로는 전송되지 않습니다 ⚠️

`sendViaFormsubmit()` 는 파일의 **이름만** 본문에 적어 보냅니다.
고객이 레퍼런스 이미지를 첨부해도 파일 자체는 버려집니다.

```js
'이미지 첨부: ' + (_selectedFiles.length > 0
  ? _selectedFiles.map(function(f){return f.name;}).join(', ') : '없음')
```

### 3. 입력칸에 `name` 속성이 없습니다

`<input type="text" class="form-field" id="atm-f-name" ...>` — `id` 만 있고 `name` 이 없어
JS 가 죽으면 폼이 빈 값으로 전송됩니다.

**이 패치는 세 가지를 한 번에 해결합니다.** 폼을 아임웹 입력폼으로 바꾸면
접수 기록·파일 첨부·필수 검증을 전부 아임웹이 맡습니다.

## 무엇이 바뀌고, 무엇이 그대로인가

| | |
|---|---|
| **그대로** | CONTACT 타이틀(`CONTACT` + `get in touch`), 소개 문구, PHONE·EMAIL·LOCATION, 하단 안내 박스, 2단 레이아웃, 색·폰트·여백 |
| **바뀜** | 우측 폼이 아임웹 입력폼으로 교체 (겉모습은 기존 `.cf-*` 디자인 그대로 재현) |
| **없어짐** | formsubmit.co 전송 코드, 동작하지 않던 파일 업로드 UI, 토스트 팝업 호출 |

## 적용 순서

### 1단계 · 아임웹 입력폼에 항목 만들기

`/admin/contents/form?board_code=b202609115a34b122e2d20` 에서
현재 폼과 **같은 항목**을 만듭니다. 순서는 자유입니다.

|---|---|---|
| 원하시는 서비스를 선택해주세요 | 선택형(체크박스·복수선택) | ✅ |
| 이름 | 한 줄 텍스트 | ✅ |

| 이메일 | 이메일 | ✅ |
| 소속 / 기관명 | 한 줄 텍스트 | |
| 희망 일정 | 한 줄 텍스트 | |
| 촬영 희망 장소 | 한 줄 텍스트 | |
| 촬영 인원 또는 규모 | 한 줄 텍스트 | |
| 활용 목적 | 선택형(체크박스·복수선택) | |
| 타겟 연령대 | 선택형(체크박스·복수선택) | |
| 타겟 성별 | 선택형(라디오) | |

| 개인정보 수집 및 이용 동의 | 약관 동의 | ✅ |

선택지 값은 현재 코드의 것을 그대로 쓰시면 됩니다.
같은 화면에서 **관리자 알림 메일**을 꼭 켜주세요 (기존처럼 메일도 받으시려면).

### 2단계 · 코드 에디터에서 3곳 수정

| 파일 | 하는 일 |
|---|---|
| `01-ADD-css.css` | **추가** — 스타일 블록 맨 끝, 닫는 `style` 태그 바로 윗줄에 붙여넣기 |
| `02-REPLACE-html.html` | **교체** — `<form class="contact-form" ... id="atm-contactForm">` 부터 그 짝인 `</form>` 까지 |
| `03-REPLACE-js.js` | **교체** — `FORMSUBMIT_ENDPOINT` 선언 줄부터 「YouTube 컨트롤」 주석 직전까지 |

각 파일 맨 위에 찾을 위치가 다시 적혀 있습니다. **저장 후 게시하기**를 누르세요.

### 3단계 · 페이지에 입력폼 위젯 놓기

코드 섹션 **바로 아래**에 아임웹 **[입력폼] 위젯**을 추가하고
`b202609115a34b122e2d20` 입력폼을 선택합니다.

스크립트가 그 위젯을 CONTACT 카드 안으로 옮겨 넣습니다.
위젯이 없으면 "입력폼을 불러오지 못했습니다" 안내가 뜨니 바로 알 수 있습니다.

### 4단계 · 확인

실제 페이지(편집기 아님)에서 확인해 주세요.

- [ ] CONTACT 타이틀·연락처·안내 박스가 **그대로**다
- [ ] 우측에 폼이 들어가 있고, 선택지가 빨간 알약 버튼으로 보인다
- [ ] 연락처에 `01012345678` 입력 → `010-1234-5678` 로 바뀐다
- [ ] 휴대폰에서 1단으로 잘 쌓인다
- [ ] **테스트 문의를 한 건 보내고** 관리자 > 입력폼에 들어왔는지 확인
- [ ] **이미지를 첨부해서** 보내고, 관리자에서 파일이 실제로 열리는지 확인
- [ ] 관리자 알림 메일이 도착했는지 확인

`_test/index.html` 은 실제 페이지의 CONTACT 구조를 그대로 재현한 테스트 파일입니다.

`.form-field`/`.form-submit` 스타일과 일치, 선택지 알약 버튼과 빨간 선택 강조,
'선택' 배지, 연락처 자동 하이픈, 파일 첨부 항목 유지, 약관 박스 높이,
formsubmit 미사용, 스타일 블록 정상, 모바일 1단·가로 스크롤 없음·16px.
