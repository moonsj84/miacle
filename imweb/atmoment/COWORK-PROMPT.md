## 작업 개요

미아클 아임웹 사이트의 **앳더모먼 메인 페이지 CONTACT 폼**을,
외부 서비스(formsubmit.co)로 나가던 것에서 **아임웹 입력폼**으로 바꾸는 작업이야.
지금은 문의가 아임웹 관리자에 기록으로 남지 않고, 첨부한 이미지도 실제로는 버려지고 있어.

```
저장소     : https://github.com/moonsj84/miacle
브랜치     : claude/kind-heisenberg-o98d9f
```

```bash
cd C:\Users\<사용자명>\Documents
git clone -b claude/kind-heisenberg-o98d9f https://github.com/moonsj84/miacle.git miacle-contact
```

내려받으면 패치 파일이 여기 있어:

```
C:\Users\<사용자명>\Documents\miacle-contact\imweb\atmoment\
    ├─ 01-ADD-css.css        ← 추가할 CSS
    ├─ 02-REPLACE-html.html  ← 교체할 HTML
    ├─ 03-REPLACE-js.js      ← 교체할 JS
    ├─ PATCH.md              ← 상세 설명 (먼저 읽어)

```

**저장소 접근이 안 되면** 거기서 멈추고 나한테 말해줘. 파일을 직접 줄게.

## 2단계 · 코드 에디터에서 3곳 수정

`디자인 편집 > 앳더모먼 > 코드 에디터`

### 2-1. CSS 추가

`01-ADD-css.css` 내용 전체를 복사해서,
코드의 **스타일 블록 맨 끝** — 닫는 `style` 태그 바로 윗줄에 붙여넣어.

기존 CSS는 **한 줄도 지우지 마.** 추가만 하는 거야.

### 2-2. HTML 교체

찾을 것 — 이 줄로 시작하는 블록:

```html
<!-- 우측: 상세 문의 폼 -->
<form class="contact-form reveal" id="atm-contactForm" action="https://formsubmit.co/miaclife@naver.com" method="POST">
```

이 `<form ...>` 부터 **짝이 되는 `</form>` 까지 전부** 선택해서
(약 250줄, `<!-- S1. 기본 정보 -->` 부터 `<button type="submit" class="form-submit" id="atm-formBtn">` 까지 포함)
`02-REPLACE-html.html` 의 내용으로 교체해.

`</form>` 바로 다음 줄의 `</div>` 와 `</section>` 은 **건드리지 마.**

### 2-3. JS 교체

찾을 것 — `FORMSUBMIT_ENDPOINT` 를 선언하는 줄:

```js
  var FORMSUBMIT_ENDPOINT = 'https://formsubmit.co/ajax/miaclife@naver.com';
```

여기부터, 아래 주석 줄 **직전까지** 전부 선택해서 교체해:

```js
  /* ── YouTube 컨트롤 (postMessage 방식) ── */
```

즉 `showToast`, `getChecked`, `getRadio`, `getVal`, 파일 업로드 UI,
폼 제출 핸들러, `sendViaFormsubmit` 이 전부 사라지고
`03-REPLACE-js.js` 내용으로 바뀌는 거야.

**YouTube 주석 줄부터 아래는 그대로 둬.**

### 2-4. 저장

**저장** 누르고, 아직 **게시하기는 누르지 마.**

## 4단계 · 실제 페이지에서 확인

`https://www.miacle.co.kr/atmoment` 를 열어서 (편집기 화면 말고 실제 페이지) 확인해줘.

- [ ] CONTACT 타이틀(`CONTACT` + 빨간 `get in touch`)이 **그대로**다
- [ ] 왼쪽 소개 문구, PHONE / EMAIL / LOCATION, 하단 안내 박스가 **그대로**다
- [ ] 오른쪽에 폼이 들어가 있다 (카드 밖에 따로 떠 있지 않다)
- [ ] 서비스 선택지가 **빨간 알약 버튼**으로 보이고, 누르면 빨갛게 채워진다
- [ ] 연락처에 `01012345678` 입력 → `010-1234-5678` 로 자동 변환된다
- [ ] 선택 항목 옆에 회색 `선택` 배지가 붙어 있다
- [ ] 휴대폰 화면 폭에서 1단으로 잘 쌓이고 좌우로 밀리지 않는다
- [ ] **테스트 문의를 한 건 실제로 보낸다** (이미지도 한 장 첨부해서)
- [ ] 관리자 > 입력폼에 그 문의가 들어와 있다
- [ ] 첨부한 이미지가 관리자에서 **실제로 열린다**
- [ ] `miaclife@naver.com` 으로 알림 메일이 도착했다

## 중단하고 물어봐야 할 상황

아래 중 하나라도 해당하면 **더 진행하지 말고 나한테 알려줘.**

- 로그인 화면이 뜬다
- 0단계 백업 저장이 안 됐다
- 찾으라는 코드 블록이 안 보이거나, 내가 알려준 것과 다르게 생겼다
- 교체 후 페이지 레이아웃이 깨졌다
- 테스트 문의가 관리자에 안 들어온다
- 첨부 이미지가 관리자에서 안 열린다

특히 **레이아웃이 깨지거나 문의가 안 들어오면** 0단계 백업 파일로 즉시 되돌려줘.
아임웹 코드 에디터 상단 **시계 아이콘(이력)** 으로도 이전 버전 복구가 가능해.
