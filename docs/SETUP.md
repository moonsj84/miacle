# 아임웹 설정 가이드

앳더모먼(`/atmoment`) 하단 CONTACT 영역을 **실제로 접수되는 입력폼**으로 만드는 절차입니다.
소요 시간은 처음 한 번 15~20분 정도입니다.

- 대상 페이지: <https://www.miacle.co.kr/atmoment>
- 연동 입력폼: `board_code = b202609115a34b122e2d20`
  ([관리자 바로가기](https://miacle.imweb.me/admin/contents/form?board_code=b202609115a34b122e2d20))

---

## 어떻게 동작하나요

접수 처리는 **아임웹 입력폼 위젯이 그대로 담당**합니다. 우리가 만든 코드는 그 위젯을
디자인된 CONTACT 카드 안으로 옮겨 넣고 보기 좋게 꾸미는 역할만 합니다.

```
[코드 위젯]  CONTACT 제목 · 소개문 · 연락처 + 빈 카드
     +                                              →  스크립트가 폼을 카드 안으로 이동
[입력폼 위젯]  b202609115a34b122e2d20
```

이 구조의 장점입니다.

- 제출·유효성 검사·스팸 차단·관리자 알림이 전부 **아임웹 기본 기능** 그대로입니다.
- 접수 내역은 평소처럼 **관리자 > 입력폼**에서 확인합니다. 별도 서버·DB가 필요 없습니다.
- 스크립트가 실패해도 폼은 원래 자리에서 정상 접수됩니다. (디자인만 기본형으로 보임)

## 1단계 · 입력폼 항목 만들기

관리자 > **콘텐츠 > 입력폼**에서 해당 입력폼을 열고 아래 항목을 만들어 주세요.

| # | 항목명 | 유형 | 필수/선택 | 옵션 · 안내문구 |
|---|---|---|---|---|
| 1 | 원하시는 서비스를 선택해주세요 | 선택형(라디오) | **필수** | 사진 촬영 / 영상 제작 (일반) / AI 영상 제작 / 브랜딩 · 디자인 / 마케팅 · 콘텐츠 기획 / 행사 · 이벤트 기록 / 기타 |
| 2 | 성함 / 담당자명 | 한 줄 텍스트 | **필수** | 안내문구: `홍길동` |
| 3 | 회사 · 브랜드명 | 한 줄 텍스트 | 선택 | 안내문구: `(주)미아클` |
| 4 | 연락처 | 한 줄 텍스트 | **필수** | 안내문구: `010-0000-0000` |
| 5 | 이메일 | 이메일 | **필수** | 안내문구: `name@example.com` |
| 6 | 희망 일정 | 한 줄 텍스트 | 선택 | 안내문구: `예) 11월 중순 촬영 희망` |
| 7 | 예산 범위 | 선택형(드롭다운) | 선택 | 300만원 미만 / 300 – 500만원 / 500 – 1,000만원 / 1,000만원 이상 / 상담 후 협의 |
| 8 | 문의 내용 | 여러 줄 텍스트 | **필수** | 안내문구: `진행하고 싶은 프로젝트, 목적, 일정, 참고 자료 등 알고 계신 만큼만 적어주셔도 충분합니다.` |
| 9 | 유입 경로 | 선택형(드롭다운) | 선택 | 검색 / 인스타그램 / 지인 소개 / 기존 거래처 / 기타 |
| 10 | 개인정보 수집 및 이용 동의 | 약관 동의 | **필수** | 아래 문안 참고 |

1번 서비스 항목은 **기존 폼의 '서비스 종류' 단계와 동일**하게 맞췄습니다.
관리자에서 **라디오(단일 선택)** 로 만들면 기존 폼처럼 알약형 버튼으로 표시되고,
드롭다운으로 만들면 목록 형태로 표시됩니다. 어느 쪽이든 디자인은 적용됩니다.

### 필수와 선택은 어떻게 표시되나요

관리자에서 **필수 여부만 켜고 끄면** 화면 표시는 자동으로 따라갑니다.

| | 화면 표시 |
|---|---|
| 필수 항목 | 항목명 뒤에 **빨간 별표** `*` |
| 선택 항목 | 항목명 뒤에 **회색 배지** `선택` |

폼 맨 위에는 `* 필수 항목 | 선택 없어도 접수됩니다` 범례가 항상 표시됩니다.
색만이 아니라 **별표와 배지라는 서로 다른 형태**로 구분하므로, 색 구분이 어려운
분들도 알아볼 수 있습니다.

> 항목을 추가하거나 필수 여부를 바꿔도 코드는 손댈 필요가 없습니다.
> 스크립트가 아임웹의 필수 설정을 읽어 `선택` 배지를 자동으로 붙이고 뗍니다.

### 개인정보 수집 및 이용 동의 문안

```
[수집 항목] 성함, 회사·브랜드명, 연락처, 이메일, 문의 내용
[수집 목적] 문의 접수 및 상담 회신
[보유 기간] 문의 처리 완료 후 1년 이내 파기
동의를 거부하실 수 있으나, 이 경우 문의 접수가 제한됩니다.
```

### 알림 설정 (놓치지 않으려면 꼭)

같은 화면의 **입력폼 설정**에서 아래를 켜주세요.

- **관리자 알림 메일** — 접수 즉시 담당자 메일로 발송
- **알림톡 / SMS** — 사용 중이라면 함께 설정
- **자동 회신 메일** — 문의자에게 "접수되었습니다" 안내
  (문안 예시: *문의해 주셔서 감사합니다. 영업일 1~2일 이내에 담당자가 연락드리겠습니다.*)

## 2단계 · 페이지에 위젯 배치

아임웹 **편집기**에서 `/atmoment` 페이지를 엽니다.

1. 하단 기존 CONTACT 영역으로 이동합니다.
2. 그 자리에 **[코드] 위젯**을 추가합니다.
3. 코드 위젯 **바로 아래**에 **[입력폼] 위젯**을 추가하고,
   목록에서 `b202609115a34b122e2d20` 입력폼을 선택합니다.
4. 기존 CONTACT 텍스트/이미지 요소는 삭제하거나 숨김 처리합니다.
   (새 코드 위젯이 제목·소개문·연락처를 모두 포함합니다)

> 두 위젯은 **같은 페이지 안**에 있기만 하면 됩니다. 위아래 순서가 바뀌어도,
> 사이에 다른 위젯이 있어도 동작합니다.

## 3단계 · 코드 붙여넣기

페이지에 맞는 파일 **전체**를 복사해 2단계에서 만든 **코드 위젯**에 붙여넣고 저장합니다.

| 페이지 | 파일 |
|---|---|
| 홈페이지 메인 | [`dist/main/imweb-code-widget.html`](../dist/main/imweb-code-widget.html) |
| 앳더모먼 | [`dist/atmoment/imweb-code-widget.html`](../dist/atmoment/imweb-code-widget.html) |

두 파일은 **문구만 다르고** 디자인·동작·접수 경로는 완전히 같습니다.

### (선택) 여러 페이지에서 쓸 경우

CSS·JS를 사이트 공통 코드로 빼면 페이지마다 중복되지 않습니다.

1. 관리자 > **사이트 설정 > SEO/헤더설정 > 헤더 태그**에
   `src/contact-form.css`를 `<style>…</style>`로,
   `src/contact-form.js`를 `<script>…</script>`로 각각 넣습니다.
2. 각 페이지의 코드 위젯에는 `src/contact-section.html`만 넣습니다.

## 4단계 · 확인

편집기 미리보기가 아니라 **실제 페이지**(`https://www.miacle.co.kr/atmoment`)에서 확인해 주세요.
편집기 화면에서는 위젯이 실제와 다르게 그려져 폼이 카드 안으로 들어가지 않을 수 있습니다.

- [ ] CONTACT 카드 **안에** 입력폼이 들어가 있다
- [ ] 카드 아래에 폼이 한 번 더 나타나지 **않는다**
- [ ] 연락처 칸에 `01012345678`을 치면 `010-1234-5678`로 자동 변환된다
- [ ] 문의 내용 아래 글자 수 카운터가 보인다
- [ ] 필수 항목엔 빨간 `*`, 선택 항목엔 회색 `선택` 배지가 붙어 있다
- [ ] 서비스 종류가 알약형 버튼으로 보이고, 고르면 테두리가 진해진다
- [ ] 휴대폰에서 세로 1단으로 잘 쌓이고, 좌우로 밀리지 않는다
- [ ] **테스트 문의를 실제로 한 건 보내고**, 관리자 > 입력폼에 들어왔는지 확인한다
- [ ] 관리자 알림 메일이 도착했는지 확인한다

## 문제가 생기면

**폼이 카드 안으로 안 들어가고 아래에 따로 보여요**
붙여넣은 코드에서 `formSelector` 를 찾아 입력폼 위젯의 선택자를 직접 지정해 주세요.
실제 페이지에서 폼을 우클릭 > 검사(Inspect)로 위젯의 `id` 나 `class` 를 확인한 뒤 넣으면 됩니다.

```js
var CONFIG = {
  formSelector: '#여기에_위젯_아이디',   // 예: '#form_b202609115a34b122e2d20'
```

**디자인이 하나도 적용되지 않아요**
아임웹 테마 CSS가 이기고 있는 경우입니다. 코드 위젯 대신 위의 *(선택) 여러 페이지에서 쓸 경우*
방법으로 **헤더 태그**에 CSS를 넣으면 더 나중에 로드되어 우선 적용됩니다.

**폼이 두 번 보여요**
코드 위젯을 두 번 붙여넣었거나, 입력폼 위젯이 두 개입니다. 편집기에서 중복 위젯을 지워주세요.

**"입력폼을 불러오는 중입니다…"에서 멈춰요**
입력폼 위젯이 같은 페이지에 없습니다. 2단계의 3번을 다시 확인해 주세요.

## 색상·문구 바꾸기

### 톤 전체를 바꾸려면

섹션 태그의 `data-atm-theme` 값 하나만 고치면 됩니다.

```html
<section class="atm-contact" id="contact" data-atm-theme="dark">
```

`dark`(현재 기본) · `light` · `auto`(기기 설정을 따라감) 중에서 고르세요.

### 색을 세밀하게 맞추려면

붙여넣은 코드 맨 위 **테마 블록**의 값만 고치면 전체에 반영됩니다.

```css
--atm-accent:  #D83426;  /* 버튼·선택 강조 = 브랜드 레드 */
--atm-paper:   #0B0B0C;  /* 섹션 배경 */
--atm-surface: #151517;  /* 폼 카드 배경 */
--atm-field:   #1C1C1F;  /* 입력칸 배경 */
--atm-radius:    10px;   /* 0 = 각진 느낌, 16px = 더 둥글게 */
--atm-field-h:   56px;   /* 입력칸 높이 */
--atm-sticky-top: 96px;  /* 상단 고정 헤더가 있으면 그 높이만큼 키우기 */
```

> `--atm-accent` 를 바꾸실 때는 **버튼의 흰 글자가 읽히는지** 확인해 주세요.
> 현재 값은 흰 글자 대비 4.73:1 로 접근성 기준(4.5:1)을 통과합니다.
> 더 밝은 빨강은 기준에 못 미칠 수 있습니다.

제목·소개문·연락처는 `src/contact-section.html` 에서 수정한 뒤 `node build.js` 를 실행하세요.
